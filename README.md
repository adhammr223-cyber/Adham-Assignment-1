# السيرة الذاتية باستخدام HTML

مشروع تعليمي لأدهم مؤيد هاشم، مبني على الكود الحالي بدون إضافة مكتبات أو إطار عمل.

## التقنيات

HTML.

## ما الذي يقدّمه؟

عرض المعلومات الشخصية والتعليم والخبرة والمهارات باستخدام العناوين والقوائم والجداول.

## التشغيل

1. نزّل المستودع أو انسخه.
2. افتح `Assignment-1.html` في متصفح حديث.
3. احتفظ بمجلدات الصور والملفات في مواقعها الحالية حتى تعمل المسارات.

## ملفات البداية

- `Assignment-1.html`

## حدود المشروع

هذا تمرين HTML؛ لا توجد وظائف خلفية أو تسجيل دخول.

## مراجعة سريعة

جرّب الصفحة على شاشة هاتف، وتنقّل بلوحة المفاتيح، وتحقق من ظهور الصور وعمل الروابط. لا يحتاج المشروع تثبيت حزم.
